# v1.2.0-preview.1

Prerelease for acceptance testing. Live PVE and installed-service acceptance is **still pending** and required before a stable release.

- Add bounded task/log paging, SMART, ZFS, storage diagnostics and backup coverage.
- Add guarded QEMU/LXC disk growth, disk and mount-point management, resource updates, structured configuration, and LXC clone/migration with stronger source/destination authorization.
- Preserve partial task/readback evidence, exclude local overrides from packages, and include license notices.

Management remains opt-in: `ReadOnly=true` and `AllowDiskResize`, `AllowDiskManagement`, `AllowResourceChanges` and `AllowDestroy=false` by default. Legacy QEMU configuration/transfer calls now enforce shared management gates; unsupported arbitrary configuration fields fail explicitly. Read the [management contracts](https://github.com/Wixely/ProxmoxMCPSharp/blob/v1.2.0-preview.1/docs/guest-management.md) before upgrading.

Local verification: 144 synthetic HTTP/MCP tests passed; all four Windows/Linux x64 package variants published; self-contained console health passed on Windows and Linux under WSL; rootless Podman linux/amd64 container health and shutdown passed. These checks do not establish live PVE compatibility or installed-service support.

**Acceptance still to do (operator, before stable release; review 2026-09-13):**

- Compare diagnostic results with selected live PVE nodes/devices and confirm each supported PVE version and least-privilege behavior.
- Exercise management against explicitly authorized disposable QEMU/LXC guests and storage, including retained volumes, pending state, task/readback outcomes and clone/migration.
- Verify the candidate with an MCP client and isolated Windows Service/systemd installations; verify Docker Engine and ARM64 runtime behavior where claimed.

Record results and cleanup in the [acceptance checklist](https://github.com/Wixely/ProxmoxMCPSharp/blob/v1.2.0-preview.1/docs/verification.md). A successful GitHub build does not complete acceptance.
